# Fairwork — Freelance Escrow MVP

A simple blockchain freelance-payment prototype.

## What is included

- A browser-based frontend in `web/`
- Demo Mode using `localStorage` (no wallet required)
- Web3-ready wallet connection via MetaMask
- ETH-based Solidity escrow contract in `contracts/FreelanceEscrow.sol`
- Milestone funding, work submission, approval/payment release, and dispute resolution

## Run the frontend

1. Open the `web` folder in VS Code.
2. Install/use a static server such as the VS Code **Live Server** extension, then open `web/index.html` with Live Server.
3. You can use the app immediately in **Demo Mode**.
4. Click **Load sample project** to see the workflow.

## Web3 / Sepolia setup

1. Install MetaMask and create/use a test wallet.
2. Switch MetaMask to **Sepolia**.
3. Open Remix and create/import `contracts/FreelanceEscrow.sol`.
4. Deploy it with an arbitrator address (for an MVP demo, this can be a separate test wallet controlled by your team).
5. Copy the deployed contract address.
6. Copy the ABI generated by Remix after compilation.
7. Put the contract address and ABI into `web/app.js`:

```js
const CONFIG = {
  contractAddress: "0x...",
  contractAbi: [ /* ABI JSON here */ ],
  chainId: "0xaa36a7",
};
```

8. Reload the page and connect MetaMask.

### Important implementation detail

The current contract accepts **native ETH**, not USDC. If you decide that Fairwork should use test USDC for dollar-denominated milestones, the contract must be changed to use an ERC-20 token interface and the frontend needs an `approve()` + `transferFrom()` flow.

## MVP demo flow

1. Create a project with a freelancer wallet and 2–3 milestones.
2. Fund a milestone.
3. Submit a work link.
4. Approve and release payment.
5. Raise a dispute on another funded milestone.

## Production hardening needed before real money

- Role/access-control improvements
- Timeout and refund rules
- Robust decentralized arbitration or multisig
- Event/indexer integration
- Server-side project metadata, authentication, and authorization
- Thorough unit/integration/security testing
- Audited smart contract
