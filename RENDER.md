# Render deployment

This is a static HTML/CSS/JavaScript MVP.

## Render settings

- Service type: Static Site
- Repository: `https://github.com/jananishankar12345-sketch/fairwork-arbitration-demo`
- Branch: `main`
- Build command: leave blank
- Publish directory: `web`

The hosted app includes Demo Mode, MetaMask Web3 mode, and the 3-member / 2-of-3 arbitration voting demo. The existing Sepolia deployment is the single-arbitrator ETH escrow contract; the voting contract in `contracts/FreelanceEscrowVoting.sol` is a reference for a future on-chain voting deployment.
